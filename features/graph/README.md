## Implementation prompt

> Use neo4j-driver in server-only Node modules. Treat PostgreSQL as source of truth and project only minimal consent-permitted data via a durable transactional outbox. Create uniqueness constraints and parameterized MERGE operations keyed by canonical IDs, with versioned idempotent replay and tombstone/deletion behavior. Model users, factors, habits, care relationships, assessments and events as described in docs/data-model.md. Namespace/filter subject and organization on all traversals, restrict depth/limits/timeouts, close sessions and authorize in PostgreSQL before exposing any graph-derived result. Handle projector failures with observable retry/dead-letter states and disclose stale context. GraphRAG retrieves scoped provenance, not unrestricted text-to-Cypher generated by an LLM. Minimize sensitive graph attributes and delete/revoke projections consistently.
